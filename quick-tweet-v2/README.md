# Quick Tweet V2

現在開いているページをX（Twitter）にすばやくツイートするためのChrome拡張機能です。

## 機能

- URLバー横の拡張機能アイコンをクリックして、現在のページをツイート
- 右クリックのコンテキストメニューから、現在のページをツイート
- ページタイトルとURLを自動的に含めてツイート画面を開きます

## ビルド方法

```bash
# 依存関係をインストール
npm install

# ビルド
npm run build

# 開発モード（ファイル変更を監視）
npm run dev
```

## Chrome拡張機能としてインストール

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `quick-tweet-v2` ディレクトリを選択

## 技術スタック

- TypeScript
- Vite
- Chrome Extension Manifest V3

## 使い方

1. 拡張機能をインストール後、ツイートしたいページを開く
2. 以下のいずれかの方法でツイート画面を開けます：
   - URLバー横の拡張機能アイコンをクリック
   - ページ上で右クリック → 「このページをツイート」を選択
3. X（Twitter）のツイート画面が新しいタブで開きます
